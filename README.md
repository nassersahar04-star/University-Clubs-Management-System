University Club Management System

Description

The University Club Management System is a Java-based application developed as part of an Object-Oriented Programming (OOP) course. The project is designed to simplify the management of university clubs by allowing users to organize club information and manage members through an object-oriented approach.

Features

* Create and manage university clubs
* Register and manage club members
* Add, update, and remove club information
* User-friendly menu-based interface
* Demonstrates the use of core Object-Oriented Programming concepts

OOP Concepts Used

* Classes and Objects
* Encapsulation
* Inheritance
* Polymorphism
* Abstraction

Technologies Used

* Java
* NetBeans IDE

Purpose

This project was developed to strengthen my understanding of Object-Oriented Programming principles and apply them to a real-world university management scenario.
